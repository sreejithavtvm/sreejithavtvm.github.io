Lexical Analysis

What the Tokenizer Ignores—and Preserves

Ignored between tokens
  • spaces, tabs, and newlines;
  • // comments;
  • /* ... */ and /** ... */ comments.
Preserved as one token

Everything between the quotes of a string constant—including spaces and punctuation—is its value.

"not // a comment"

Comment removal must therefore respect whether the scanner is currently inside a string.

Exercise 2

What Should Survive Tokenization?

let message = "a // b"; // explain the value
let x = 7/* old value */+2;
  1. Is // inside the string a comment?
  2. Does removing the block comment merge 7 and +?
Answer: The string remains one token with value a // b; the second statement tokenizes as let x = 7 + 2 ;.

JackTokenizer

A Small, Testable Interface

hasMoreTokens()Is another token available?
advance()Make the next token current.
tokenType()Classify the current token.
keyWord() / symbol()Return a keyword or symbol value.
identifier()Return the identifier text.
intVal() / stringVal()Return the constant's value.

The value-specific routine is called only when tokenType() reports the matching type.
