Grammars, parse trees, and recursive descent.

Parsing

A Token Stream Is Not Yet a Program

The tokenizer can recognize every token in both sequences. Only one follows the language's structural rules.

let x = x + 1;
let = x 1 + ;

Parsing determines whether the tokens fit the grammar and identifies the construct formed by each group.

Grammars

Rules for Building Valid Constructs

Terminal

A token that appears in the source, such as while, (, or an identifier.

Non-terminal

A higher-level construct formed from terminals and other non-terminals, such as an expression or statement.

Context-free grammar

A set of rules describing how each non-terminal can be formed from simpler elements.

Grammars

Read a Grammar in Both Directions

Construct: use the rules to generate a valid program.

Analyze: use the same rules to explain the structure of a given program.

The Result Is Hierarchical

Matching the token stream against nested grammar rules uncovers a hierarchy called a parse tree or derivation tree.

Recursive Descent

Turn Every Grammar Rule into a Routine

statement→compileStatement()
whileStatement→compileWhile()
expression→compileExpression()
term→compileTerm()

When a rule contains a non-terminal, its routine calls the routine for that non-terminal. The call structure mirrors the parse tree.

Recursive Descent

Tracing a While Statement

while (count < 100) { let count = count + 1; }
  1. compileWhile() consumes while and (.
  2. It calls compileExpression() for count < 100.
  3. It consumes ) and {.
  4. It calls compileStatements(), which calls compileLet().
  5. Finally, it consumes the closing }.
Choosing a Rule

The Current Token Usually Decides

let→compileLet()
if→compileIf()
while→compileWhile()
do→compileDo()
return→compileReturn()

Jack was designed so that the first token usually identifies the alternative. Parsing a term that begins with an identifier requires one-token lookahead.

Syntax Errors

A Failed Expectation Reveals the Error

while (x < 10 { let x = x + 1; }

After compiling the expression, the grammar requires ). The parser sees { instead.

A useful diagnostic records:what was expected;what was found;where it was found.

The same grammar that recognizes valid programs helps identify invalid ones.
