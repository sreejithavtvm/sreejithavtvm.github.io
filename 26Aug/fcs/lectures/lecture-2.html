Boolean algebra

An algebra with only two values

George Boole developed an algebra for reasoning about true and false statements. Digital designers use the same structure for signals with two logical states.

Values

0 and 1

Operations

NOT, AND, OR, and combinations of them

Like ordinary algebra, it gives us variables, expressions, identities, and rules for transformation.

Meaning

A bit can represent any two-way distinction

0false1true
0off1on
0closed1open
0no carry1carry

The symbols do not carry meaning by themselves. The designer defines what each value means in the current problem.

Boolean variables

Name the facts that matter

A Boolean variable can hold exactly one of two values: 0 or 1.

doorOpen = 1 armed = 1 correctPin = 0

Once facts are encoded as variables, Boolean operators can combine them into new facts.

For each variable above, say in words what 0 and 1 mean.

Operator 1

NOT reverses one Boolean value

NOT a is true exactly when a is false.

Common notation: ¬a, !a, or a'.

Example: if doorOpen = 1, then NOT doorOpen = 0.

AND requires every condition

a AND b is true only when both inputs are true.

Common notation: a ∧ b, a & b, or a · b.

An ATM dispenses cash if the PIN is correct AND the balance is sufficient.

OR accepts either condition

a OR b is true when at least one input is true. It is also true when both are true.

Common notation: a ∨ b or a + b.

Tutorial 1

Translate a rule into Boolean logic

A lab door should unlock when a student has a valid ID card and the lab is open.

validCard labOpen unlock

Write an expression for unlock. Then test it for all four possible input combinations.

unlock = validCard AND labOpen

The output is 1 only for validCard = 1 and labOpen = 1.

Composition

Expressions turn simple facts into policies

Suppose staff may enter even when the lab is closed:

unlock = validCard AND (labOpen OR staffOverride)
  1. Evaluate the expression inside the parentheses.
  2. Use that result as an input to the outer AND.
  3. The final value becomes the output unlock.

Parentheses make the intended grouping explicit, just as in arithmetic.

Tutorial 2

Evaluate from the inside out

Let validCard = 1, labOpen = 0, and staffOverride = 1.

validCard AND (labOpen OR staffOverride)

(0 OR 1) = 1, then 1 AND 1 = 1. The door unlocks.

Complete specification

A truth table leaves no input case unstated

Input columnsEvery variable the rule receives
One row per caseEvery possible input combination
Output columnThe required result for each case

Two expressions are equivalent if their output columns match for every row.

A truth table describes what a component does without saying how it is built.

Constructing a truth table

List the inputs systematically

With n Boolean inputs, there are 2n combinations.

  • 1 input gives 2 rows.
  • 2 inputs give 4 rows.
  • 3 inputs give 8 rows.

The input rows count in binary: 00, 01, 10, 11.

Counting functions

How many rules can two inputs define?

Two inputs create four rows. For each row, we may independently choose output 0 or output 1.

4input combinations
→
2 choicesfor each output row
→
24 = 16two-input Boolean functions

The familiar AND and OR functions are only two members of this set of sixteen.

Quick check

How many three-input Boolean functions?

Three inputs produce 23 = 8 truth-table rows. Each row's output can independently be 0 or 1.

There are two output choices for each of eight rows: 28 = 256 functions.

Canonical representation

Every truth table can become an expression

Focus on the rows where the required output is 1.

1

Write one AND term that matches each selected row.

2

Use the variable for a 1 and its NOT for a 0.

3

OR all those row terms together.

This construction is called a sum of products: an OR of several AND terms.

From algebra to hardware

An operator can become a gate

Inputsa, b
→
RuleAND

Outputout

A logic gate is a physical component that implements a Boolean function.

The truth table is its public contract. Its internal circuit is its implementation.

Gate logic

Primitive and composite gates

Primitive

Treated as an available building block at the current level.

In our course, NAND is the primitive gate.

Composite

Built by connecting simpler gates.

Once built, it can itself be used as a new building block.

Whether a gate is “primitive” depends on the abstraction level, not on nature.
