Flow of Control

Why Straight-Line Code Is Not Enough

High-level idea
while (x > 0) {
  x = x - 1;
}
Question for machine language

After testing x, which instruction should execute next?

Flow of control is the rule that decides the next instruction.

Flow of Control

The Jump Field

jumpcondition on ALU output
JGTgreater than 0
JEQequal to 0
JGEgreater than or equal to 0
JLTless than 0
JNEnot equal to 0
JLEless than or equal to 0
JMPalways jump

The condition is tested on the ALU output produced by that same C-instruction.

Flow of Control

Where Does a Jump Go?

@END
D;JLE
Meaning
@END
Load the target address into A.
D;JLE
Compute D; if the result is less than or equal to 0, jump to the instruction address currently in A.
Otherwise
Continue with the next instruction.

The Program Counter from Lecture 10 is what actually changes the next instruction address.

Flow of Control

Conditional and Unconditional Forms

conditionalD;JGT

Jump only if the computed value D is positive.

unconditional0;JMP

Compute a harmless value, then always jump. There is no destination.

Label rule
Form
(NAME)
Meaning
Name the ROM address of the next real instruction.
Important
A label is a pseudo-command. It produces no machine instruction and consumes no ROM address.

Input and Output

Memory-Mapped Input/Output

Screen

SCREEN = 16384

The 512-by-256 monochrome display occupies 8K words, 16 pixels per word.

Keyboard

KBD = 24576

After @KBD, reading M gives 0 if no key is pressed and a key code otherwise.

Key idea

There are no special screen or keyboard instructions. Programs use ordinary RAM reads and writes.

Summary of This Lecture

Labels
