Inputs: inM[16], instruction[16], reset

Outputs: outM[16], writeM, addressM[15], pc[15]

Function: Execute the current Hack instruction. If reset=1, make the next program address 0.

Hack CPU | Instruction Decoding

The First Bit Determines the Meaning

A-instruction0 vvvvvvvvvvvvvvv

Load the 15-bit constant into A.

C-instruction111 a cccccc ddd jjj

a,c: compute   d: destination   j: jump

For an A-instruction: A must load the instruction constant.

For a C-instruction: the fields control the ALU, destinations, and jump logic.

Hack CPU | Instruction Execution

Compute, Then Route the Result

ALU inputs
  • x = D
  • y = A when a=0
  • y = inM when a=1
ALU function
  • The six c-bits connect to zx,nx,zy,ny,f,no.
  • The ALU produces the result, zr, and ng.
Destinations
  • dA loads A
  • dD loads D
  • dM requests a Memory write

Destination bits are control signals only in a C-instruction. Thus writeM = i AND dM.

Hack CPU | Jump Control

Choose the Next Instruction

ALU status

zr=1: result is zero

ng=1: result is negative

positive = !zr AND !ng

Program Counter rule

If the C-instruction's jump condition accepts the ALU result, load PC=A.

Otherwise, increment the PC.

If reset=1, reset wins: PC=0.

A taken jump uses the A-register value that was already present at the start of the clock cycle.

Next: Present RAM, screen, and keyboard as one Memory chip.

Hack Memory

One Logical Address Space, Three Devices

RAM16K0–16383
Screen16384–24575
Keyboard24576
Invalid>24576

Chip name: Memory

Inputs: in[16], load, address[15]

Output: out[16]

Function: Read the addressed word continuously. If load=1, write in to the addressed writable device in the next cycle.

Screen behaves like writable RAM and refreshes pixels. Keyboard is read-only and continuously reports the current key code, or 0.

The Hack Computer

The Top-Level Contract and Wiring

Chip name: Computer

Input: reset

Function: When reset=0, execute the program stored in ROM. When reset=1, restart at instruction address 0.

ROM32KInput: address[15]Output: out[16]Function: out=ROM[address]; the program is preloaded.

The Computer needs no ordinary data pins: programs communicate through its memory-mapped screen and keyboard.

  2. Which component computes D+1? The CPU's ALU
  3. Where is the result written? Memory address 100
